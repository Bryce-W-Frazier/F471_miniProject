# Snake Mini Project
Snake Mini Project for CS471 this project was developed using python, pygame. Kanban was used as the development process!<br>
written by: Michael Baran, Bryce Frazier, and Logan Johnson
# Build
## Prerequisites
- python>=3.13
- pip
## Installation
1. Clone the repo https://github.com/Bryce-W-Frazier/F471_miniProject
2. cd F471_miniProject
3. pip install pygame
4. python game-loop.py
